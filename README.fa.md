## چرا WinTime؟

* **🚀 حجم بسیار کم (~۶۰ کیلوبایت):** یک ابزار کوچک ویندوزی بدون نرم‌افزار جانبی، مفسر یا پکیج‌های حجیم همراه برنامه.

* **⚡ اجرای سریع:** با تمرکز بر زمان اجرای کم و حداقل سربار طراحی شده است.

* **✨ رابط کاربری مدرن ویندوز:** رابط دارک تمیز، آیکون‌های برداری اختصاصی و چیدمان سازگار با تنظیمات مختلف DPI ویندوز.

* **🎯 فیدبک زنده:** هر عملیات وضعیت خود را به‌صورت فوری، مانند `در حال پردازش`، `موفق` یا `خطا` نمایش می‌دهد.

* **🔍 متن‌باز و شفاف:** سورس کامل پروژه در همین مخزن قرار دارد و امکان بررسی و کامپایل آن وجود دارد.

## قابلیت‌ها

### ۱. 🎮 پریست‌های یک‌کلیکی زمان بازی

* تنظیم ساعت سیستم روی زمان از پیش تعیین‌شده `2019-10-15 21:31:00` که در پریست RDR2 استفاده می‌شود.

* استفاده از دسترسی `SeSystemtimePrivilege` ویندوز که برای تغییر ساعت سیستم مورد نیاز است.

### ۲. 🔄 همگام‌سازی ساعت سیستم

* **Windows Time (`w32tm`):** همگام‌سازی مجدد ساعت با سرورهای زمان فعلی ویندوز با استفاده از `w32tm /resync /force`.

* **سرویس‌های عمومی NTP:** پشتیبانی از سرویس‌ها و سرورهای عمومی مانند `time.cloudflare.com`، `time.google.com`، `pool.ntp.org` و `time.windows.com` برای تست اتصال و همگام‌سازی زمان.

* **پشتیبان HTTPS:** در صورتی که UDP پورت ۱۲۳ در دسترس نباشد، برنامه می‌تواند بسته به سرویس انتخاب‌شده از یک منبع زمان مبتنی بر HTTPS استفاده کند.

### ۳. ⚙️ مدیریت سرورهای NTP

**افزودن سرور دلخواه:**

* بررسی DNS قبل از اضافه کردن سرور.
* تست اتصال UDP روی پورت ۱۲۳.
* اعتبارسنجی اولیه نام سرور.
* تنظیم سرویس Windows Time با پیکربندی مناسب کلاینت NTP.

**حذف سرورها:**

* حذف تکی سرورهای تنظیم‌شده.
* وجود بررسی‌های ایمنی برای جلوگیری از حذف تصادفی آخرین منبع قابل استفاده زمان.

**پریست‌های آماده:**

* **⭐ بهینه‌شده برای ایران:** ترکیبی از سرورهای عمومی بین‌المللی و سرورهای منطقه‌ای.
* **🌐 جهانی:** Cloudflare، Google و NTP Pool.
* **🪟 پیش‌فرض ویندوز:** بازگردانی `time.windows.com`.

### ۴. 📅 تنظیم دستی ساعت سیستم

* انتخاب سال، ماه، روز، ساعت و دقیقه.
* بازگشت سریع به زمان فعلی سیستم.

### ۵. ⚡ نسخه گرافیکی + خط فرمان

* **GUI (`WinTime.exe`):** رابط گرافیکی سبک برای ویندوز.
* **CLI (`WinTime.ps1`):** موتور مدیریت خط فرمان مبتنی بر PowerShell، شامل مدیریت سرورها و قابلیت تعمیر سرویس Windows Time به همراه پشتیبان‌گیری و بازیابی تنظیمات سرورها.

## 🔨 ساخت محلی

برای ساخت WinTime نیازی به Visual Studio ندارید.

فقط اجرا کنید:

```cmd
build.bat
```

این اسکریپت `Program.cs` را کامپایل کرده و فایل `WinTime.exe` را تولید می‌کند.

> پیش‌نیازهای ساخت به کامپایلر و کامپوننت‌های .NET Framework موجود روی نسخه ویندوز بستگی دارد. پروژه کامپایلر یا Runtime جانبی را همراه خود ارائه نمی‌کند.

## 🇮🇷 اتصال به سرورهای NTP در شبکه‌های مختلف

برخی شبکه‌ها ممکن است پورت UDP ۱۲۳، که پورت استاندارد NTP است، را محدود یا دچار اختلال کنند.

WinTime برای این شرایط، سرورهای جایگزین NTP و در صورت پشتیبانی سرویس انتخاب‌شده، یک روش پشتیبان مبتنی بر HTTPS ارائه می‌کند.

پریست **Iran-Optimized** برای ارائه گزینه‌های اتصال منطقه‌ای بیشتر طراحی شده است. دسترسی و تأخیر واقعی سرورها به ISP و شرایط شبکه کاربر بستگی دارد.
